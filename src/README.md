# 🎨 Art Gallery Landing

Интерактивный лендинг с набором UI-модулей: модальные окна, формы с валидацией, калькулятор стоимости, фильтрация и слайдер.

Проект реализован на чистом JavaScript с упором на работу с DOM, событиями и модульную архитектуру без использования фреймворков.

##  Технологии

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API


##  Функционал

- 📱 Адаптивное бургер-меню
- 🪟 Модальные окна с блокировкой скролла
- 🖼️ Слайдер с автопрокруткой и управлением
- 🧮 Калькулятор стоимости с поддержкой промокода
- 📂 Фильтрация элементов по категориям
- 📝 Формы с валидацией и отправкой данных
- 🎯 UI-анимации и интерактивные элементы
- 📸 Замена изображений при hover
